# LumineStore — Маркетплейс аккаунтов Genshin Impact

**LumineStore** - это современное веб-приложение для продажи игровых аккаунтов (нероллов) с примогемами. Проект разработан в рамках курсовой работы и представляет собой полноценный Fullstack-сервис с системой авторизации, личным кабинетом, балансом и админ-панелью.

---

## 🚀 Основные возможности

### Для пользователей:
*   **Каталог товаров**: Удобный поиск с фильтрацией по серверам (Asia, Europe и др.), номиналу примогемов и цене.
*   **Личный кабинет**: Отображение истории покупок. Все купленные логины и пароли сохраняются в профиле.
*   **Система баланса**: Возможность пополнения внутреннего счета для совершения покупок.
*   **Безопасность**: Защищенный вход через JWT-токены и хеширование паролей (bcrypt).

### Для администраторов:
*   **Управление лотами**: Создание, редактирование и удаление товаров через удобный интерфейс.
*   **Управление стоком**: Система автоматического списания аккаунтов из пула при покупке.
*   **Список пользователей**: Просмотр всех зарегистрированных клиентов.

---

## 🛠 Технологический стек

*   **Frontend**: React (Vite), React Router v6, Axios.
*   **Backend**: Node.js, Express.
*   **База данных**: MongoDB + Mongoose (ODM).
*   **Авторизация**: JSON Web Tokens (JWT) + bcryptjs (хеширование).
*   **Стилизация**: Vanilla CSS (современная верстка, адаптив, темная тема).

## 📦 Установка и запуск

### 1. Требования
Убедитесь, что на вашем компьютере установлены:
*   [Node.js](https://nodejs.org/) (версия 16+)
*   [MongoDB Community Server](https://www.mongodb.com/try/download/community)

### 2. Запуск Базы Данных (MongoDB)
Запустите MongoDB локально. В Windows это можно сделать через PowerShell:
```powershell
Start-Process "C:\Program Files\MongoDB\Server\8.2\bin\mongod.exe" -ArgumentList "--dbpath C:\data\db"
```

### 3. Настройка Бэкенда
Перейдите в папку сервера и установите зависимости:
```bash
cd server
npm install
```
Создайте файл `.env` в папке `server` и добавьте настройки (примеры есть в коде):
```env
PORT=5000
MONGO_URI=mongodb://localhost:27017/luminestore
JWT_SECRET=your_secret_key_here
```

### 4. Наполнение базы (Seed)
Для автоматического создания тестовых товаров и пользователей выполните команду в папке `server`:
```bash
npm run seed
```

### 5. Запуск приложений
**Запуск сервера:**
```bash
cd server
npm run dev
```

**Запуск фронтенда:**
```bash
cd client
npm install
npm run dev
```
После этого сайт будет доступен по адресу: `http://localhost:5173`

## 📜 Структура проекта
*   `/server` — серверная часть (Express, API, модели БД).
*   `/client` — клиентская часть (React компоненты, страницы, стили).
*   `/server/models` — схемы данных Mongoose.
*   `/client/src/context` — глобальное состояние авторизации.
